# Ekran spesifikasyonları (1–26)

Hi-fi: 3, 6, 10, 11 (`screens/`). Diğerleri aşağıdaki bileşen/davranış spesifikasyonuyla, aynı token ve bileşenlerle uygulanır; Faz 2'de hi-fi'ları eklenecek.

1. **Splash** — `SplashScreen API`: `windowSplashScreenBackground = surface0`, `windowSplashScreenAnimatedIcon = ic_splash` (240dp, 160 çap içinde), alt marka `ic_splash_branded`. Çıkış: ikon 1→.8 ölçek + fade 250 ms, Ana sayfa alttan 24dp fade-in.
2. **Karşılama** — Üst 40 %: hilal işareti 96 + glow. displayMedium `welcome_title`, bodyLarge `welcome_subtitle`. Birincil "Spotify'a bağlan" (WebView Custom Tab; not metni `welcome_spotify_note` bodySmall text3 + lock 16 ikon). İkincil "Spotify olmadan keşfet". İzinler: bağlantı sonrası 2 adımlı sayfa (bildirim, ses dosyaları) — her biri ikon 48 + başlık + gövde + "İzin ver"/"Şimdi değil". Reddedilince `perm_denied_*` kartı + "Ayarları aç".
3. **Ana sayfa** — hi-fi. Ek bölümler aynı kalıpta: Popüler sanatçılar (daire 96), Çalma listelerin (116 karo), "X dinleyenler…" (116 karo), "Bu hafta" istatistik kartı (168×104, mono büyük süre).
4. **Ara** — Arama kutusu 52 (sabit üstte). Boş: Son aramalar (satır 48, geçmiş ikonu, sağda ×), Türler ızgarası 2 sütun 96 yükseklik karolar (`surface2`, sol üst titleMedium, sağ alt 40° dönük kapak yer tutucu). Sonuçlar: `PrimaryScrollableTabRow` 5 sekme, gösterge 2dp accent. Pano/klavyeden link gelince üstte "Link algılandı" kartı: `surface2` 12 köşe, kaynak rozeti + başlık + "Aç" / "Çal" pill 36.
5. **Kitaplık** — Üst: başlık + grid/list toggle 48 + sırala 48 + "+" 48. Çip şeridi 36. Sabit "Beğenilen Şarkılar" satırı 72 (gradyan kapak accent→surface3, kalp ikonu, "%d şarkı"). Liste 72 satırı / grid 2 sütun 172 kapak. Klasörler: folder ikonu karo, içinde sayı. "+" sheet: Yeni liste / İçe aktar / Yeni klasör.
6. **Liste detayı** — hi-fi. Liste içi arama: üst bar ara ikonuna basınca 52 arama kutusu kayar. Sıralama sheet: Özel / Başlık / Sanatçı / Eklenme / Süre.
7. **Beğenilen Şarkılar** — Liste detayı şablonu; kapak gradyan; sahip yok; boş durum `library_empty_liked_*`.
8. **Albüm detayı** — Liste detayı şablonu; kapak 148; alt satır sanatçı avatar 20 + yıl · şarkı sayısı; satırlarda kapak yerine 2 haneli mono numara (28 genişlik).
9. **Sanatçı detayı** — Hero 280: avatar yer tutucu bulanık arka plan + 120 daire; isim displayMedium; "Takip et" pill ikincil + "Radyo başlat" pill ikincil + more. Popüler (5 satır, numara), Albümler/Tekliler segment + 132 şerit, Benzer sanatçılar daire 96 şeridi.
10. **Mini oynatıcı** — hi-fi (REDLINES).
11. **Şimdi Çalıyor** — hi-fi. Karıştır ikinci dokunuş → shuffle-smart (kıvılcım) + snackbar "Akıllı karıştırma açık · sıraya öneriler eklendi". Hız sheet: 0.5–3× slider + 0.25 adım çipleri. Uyku: 5/15/30/45/60 dk / Şarkı bitince. Çıkış: `MediaRouter` listesi.
12. **Sözler** — Sheet "Şarkı sözleri": satırlar bodyLarge 18/500 text3, aktif satır headlineSmall 22/700 text1 (ölçek 1→1.08 250 ms), ortalanır; dokununca seek + 150 ms accent flaş. Alt: kaynak `lyrics_source` mono 11 + zamanlama ±0.25 stepper (−/+ 40, değer mono). Karaoke: fullscreen ikonu → tam ekran, kapak bulanık arka plan, satır dolumu accent (README), kontroller 3 sn'de gizlenir. Durumlar: `lyrics_not_found_*`, `lyrics_instrumental` (ikon music-note + nota dalgası).
13. **Sıra** — Sheet: "Şimdi çalıyor" sabit satır; "Sıradaki" başlık + sağda "Sırayı temizle" / "Dışa aktar" metin butonları; satırlar drag-handle 40 sağda, `ReorderableLazyColumn`; sola kaydır → kaldır + undo snackbar; ÖNERİLEN satırlar `accent.container` sol şerit 2dp; "Az önce çalanlar" katlanır bölüm text3.
14. **Kaynağı değiştir** — Sheet: başlık + mevcut kaynak (işaretli). Aday satırı 88: küçük resim 112×64 (6 köşe) + başlık 2 satır 14/600 + kanal 12 text2 + süre mono + eşleşme rozeti (≥90 accent, 70–89 warning, <70 text3). Satırda "Önizle" 36 pill (çalan önizlemede pause) ve dokununca "Seç".
15. **Şarkı menüsü** — Sheet: üst 72 bölüm kapak 56 + başlık/sanatçı; satırlar 56 (COMPONENTS). Sıra: Sonra çal, Sıraya ekle, Listeye ekle, Beğen, İndir, Radyo başlat, Sanatçıya git, Albüme git, Kaynağı değiştir, Paylaş, Bağlantıyı kopyala; ayraç; Engelle (şarkı), Engelle (sanatçı), Çevrimdışından çıkar, İndirileni sil — `error`.
16. **Radyo** (Yayın › Radyo) — Üst segment Radyo | Podcast. Arama 52. Favoriler (daire 72 logolar yer tutucu), Son dinlenenler satır 60, Türler çip akışı, Ülkeler karo 2 sütun 72, Popüler istasyonlar satır 60 (sağda favori kalp). Çalan istasyon: mini oynatıcıda süre yerine "Canlı" rozeti; Şimdi Çalıyor'da ilerleme yerine "Canlı" + şu an çalan şarkı metni 14 text2; "Bağlanıyor…" belirsiz çubuk.
17. **Podcastler** — Abonelikler ızgara 3 sütun 108 kapak + sayı rozeti; "Ülkende popüler" 132 şeridi; "RSS adresiyle ekle" satır 56 + rss ikonu → diyalog URL. Program detayı: kapak 148 + başlık + yayıncı + "Abone ol" pill + bölüm listesi 88 (tarih mono 11 text3, başlık 2 satır, kalan süre + 3dp ilerleme, indir 40). Bölüm detayı: başlık displaySmall, açıklama bodyMedium (genişlet), "Kaldığın yerden devam et" birincil + "Oynatıldı işaretle" ikincil + indir.
18. **İndirilenler** — Depolama kartı 96 (kullanılan/sınır mono 18 + 4dp çubuk). Aktif indirmeler satır 60 + halka göstergesi. Çevrimdışı koleksiyonlar satır 72: kapak + ad + "%d / %d" + 3dp ilerleme + "Şimdi senkronla" / "Duraklat" / "Tekrar dene" metin butonları (durum: senkron, duraklatıldı, hata `error`). Hariç tutulanlar katlanır bölüm. Boş durum `downloads_empty_*`.
19. **Yerel dosyalar** — Üst "Klasör ekle" pill ikincil (SAF). Segment Şarkılar | Albümler | Sanatçılar. Satır 60 (dosya biçimi mono rozet FLAC/MP3). "Taranıyor…" shimmer.
20. **İstatistikler** — Segment 7 gün | 30 gün | Tüm zamanlar. Toplam süre displayLarge mono (44). En çok dinlenen 3 bölüm (satır 60 + sağda "%d çalma" mono). Isı haritası kartı (README). "Yıl özeti" kartı 168 → 9:16 story kartı: surface0 zemin, accent glow, hilal işareti, displayLarge sayılar, top 5 liste; `Bitmap` paylaşımı. "Spotify geçmişini içe aktar" satır 56 (JSON zip).
21. **Ayarlar** — Profil üst kartı 88 (avatar 56 + ad + "Spotify hesabı" / "Çıkış yap"). Gruplar: başlık overline mono + satırlar 56 (ikon 24 text2, başlık bodyLarge, değer bodyMedium text2 sağda / switch). Alt sayfalar aynı kalıp; sliderlar değer mono. Görünüm: tema segment (Sistem/Koyu/Açık), vurgu modu radyo 3 satır, sabit renkte 12 daire 40 paleti + "Özel" (HSL slider, sınır dışı değerler otomatik sıkıştırılır ve bilgi metni).
22. **Ekolayzer** — Üst: açma switch + hazır ayar çipleri. Eğri `Canvas` 240 yükseklik (README). Altta 10 bant etiketi mono 10 (31 Hz … 16 kHz), değerler mono 11. Preamp dikey slider sağda 48 geniş.
23. **İçe/dışa aktar** — Adım göstergesi 3 nokta. 1) Dosya seç (SAF) / YouTube listesi linki alanı. 2) Önizleme: özet kart (bulunan / okunamayan sayıları mono 18), eşleşen satırlar 60 (eşleşme rozeti), okunamayanlar `warning` ikonlu katlanır liste. 3) "Oluştur" birincil → ad alanı. Dışa aktar sheet: biçim radyo (M3U8, CSV, XSPF, JSON) + "Dışa aktar".
24. **Genel durumlar** — Shimmer, boş durum, hata, çevrimdışı banner (36 yükseklik `surface3` üstte, offline ikon + `state_offline` 12), snackbar, onay diyaloğu, izin reddedildi — COMPONENTS.
25. **Sistem yüzeyleri** — Medya bildirimi (`MediaStyle`, `ic_notification`), kilit ekranı (sistem), widget 4×1 / 4×2 (README), Android Auto göz atma (README).
26. **Tablet / ≥840dp** — `NavigationRail` 80 geniş, üstte avatar, altta mini oynatıcı dikey varyantı (kapak 56 + play). Ana sayfa: içerik max 1200, karo şeritleri 2 satır ızgaraya dönüşür. Şimdi Çalıyor: iki sütun — sol 45 % (kapak ≤ 480, kontroller), sağ 55 % (Sıradaki | Sözler | İlgili sekmeleri kalıcı). Liste detayı: liste-detay (sol Kitaplık 360, sağ detay).
